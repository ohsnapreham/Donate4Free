# Donate4Free

Donate4Free started with a simple idea: give people a way to support charitable causes with their time. The original initiative used YouTube videos to generate ad revenue intended for charitable donations. The website introduces the idea, shares the founder’s story, and links to the channel.

[Visit the live site](https://donate4free.netlify.app/)

## Local preview

The site uses plain HTML, CSS, and JavaScript. No install or build step is required. With Python 3 installed, run these commands:

```sh
git clone https://github.com/ohsnapreham/Donate4Free.git
cd Donate4Free
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000).

## Project files

| Path | Purpose |
| --- | --- |
| `index.html` | Homepage content and links |
| `css/style.css` | Layout, typography, and responsive styles |
| `js/index.js` | Navigation menu behavior |
| `img/` | Site images and restored Donate4Free logo and monogram |

## Deployment

The live site is hosted on Netlify. The repository root contains the publishable files and can be served directly without a build command.
